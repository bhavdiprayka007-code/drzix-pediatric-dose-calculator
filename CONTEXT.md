# Drzix Pediatric Dose Calculator

## Vision
Offline-first pediatric dose calculator for Indian clinicians.

## Stack
- HTML
- CSS
- JavaScript
- PWA

## Current milestone
Milestone 3 is in progress. The app now includes more validated pediatric medicines, age-aware alternatives, and a browser-based engine smoke test.

## Rules
- Validate every drug against trusted references before release.
- Never remove hard safety blocks.
- Keep app offline-first.
- Keep medical logic out of the UI.
