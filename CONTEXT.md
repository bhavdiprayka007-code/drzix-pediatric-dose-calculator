# Drzix Pediatric Dose Calculator

## Vision
Offline-first pediatric dose calculator for Indian clinicians.

## Stack
- HTML
- CSS
- JavaScript
- PWA

## Current milestone
Milestone 1 foundation is now live in the repository.

- Apple-style app shell
- Bottom navigation
- Home screen
- Search screen
- Drug Dose screen
- Starter pediatric drug dataset
- WHO-based weight estimation
- Dose and safety engine scaffolding
- PWA manifest and service worker
- Project operating docs

- Never remove hard safety blocks.
- Keep app offline-first.
- Keep medical logic out of the UI.
