# Project Rules

- Never invent medical doses.
- Never remove hard safety checks.
- Keep the UI mobile-first and fast.
- Keep medical logic out of the UI layer.
- Keep data in structured files.
- Update CONTEXT.md after major milestones.
- Update CHANGELOG.md when capabilities change.
- Prefer simple, readable vanilla JavaScript.
- Preserve offline behavior.
- Show clear alternatives when a drug is not suitable for the selected age group.
