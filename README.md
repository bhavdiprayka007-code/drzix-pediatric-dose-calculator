# Drzix Pediatrics

Offline-first pediatric clinical support for Indian doctors.

## What this build includes
- Apple Health inspired UI
- Home, Search, Drug Dose, and Settings screens
- Bottom navigation
- Pediatric drug database
- WHO-based weight estimation
- Dose and safety engine
- PWA shell for GitHub Pages

## Tech stack
- Vanilla HTML
- Vanilla CSS
- Vanilla JavaScript
- Static JSON data files

## Current status
Milestone 1 is focused on the project foundation and the first working pediatric dose workflow.

## Safety note
This project is a clinical support tool. It must never replace clinical judgment, local protocols, or specialist review.
