# Drzix Pediatrics

Offline-first pediatric clinical support for Indian doctors.

## What this build includes
- Apple Health inspired UI
- Home, Search, Drug Dose, Injectables, Fluids, and Settings screens
- Bottom navigation
- Starter pediatric drug database
- WHO-based weight estimation
- Dose and safety engine scaffolding
- Injectable dose workflow
- IV fluid workflow
- More validated pediatric medicines with age-aware alternatives
- Browser smoke test page for the dose engine
- PWA shell for GitHub Pages

## Tech stack
- Vanilla HTML
- Vanilla CSS
- Vanilla JavaScript
- Static JSON-like starter data in JavaScript for the first milestone

## Current status
Milestone 3 is underway. The app now has more validated pediatric medicines, age-aware alternatives, and a smoke test page so the engine is easier to trust.

## Safety note
This project is a clinical support tool. It must never replace clinical judgment, local protocols, or specialist review.
