# AI Contributor Guide

You are contributing to the Drzix Pediatric Dose Calculator.

## Goal
Build an offline-first pediatric clinical support app using HTML, CSS and JavaScript.

## Priorities
1. Patient safety.
2. Accurate medical calculations.
3. Simple mobile UI.
4. Offline operation.

## Before making changes
- Read CONTEXT.md.
- Preserve architecture.
- Never invent medical doses.
- Keep database normalized.

## Required updates
After every major change:
- Update CONTEXT.md
- Update CHANGELOG.md
- Record architecture decisions.

## Database
Every drug should include indications, age limits, dose ranges, strengths, contraindications, warnings, alternatives, references and verification status.

## Coding
- Vanilla HTML/CSS/JS
- Mobile-first
- Modular files
- No unnecessary frameworks

## Long-term modules
Pediatric drugs, adult drugs, emergency, IV fluids, AI assistant, guidelines, calculators.
